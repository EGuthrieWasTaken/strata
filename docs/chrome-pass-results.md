14. **F14 · major (security and privacy) · V4 · the Preview request puts the session token and the reason in the address**
   - Steps: `/criteria/INC-02/edit`, fill the form, press **Preview**.
   - Actual: the page URL becomes `/criteria/INC-02/edit?csrf_token=<token>&definition=...&direction=tightened&rationale=...`. The wiki says changes are accepted only as POST requests carrying a CSRF token and that the session token is kept in a cookie that other sites cannot read; this page shows it in plain sight. (Preview is a GET form.)
